# Unity Custom Planet Generator & Gravity System

Реалистичный инструмент для создания процедурных круглых планет в Unity и кастомная система гравитации к центру сферы. Проект создан разработчиком **Mikhailgames** для симулятора выживания **MoonCraft**.

## 🚀 Основные фишки проекта (Features)

* **Custom Gravity System:** Полная замена стандартной физики Unity. Скрипт отключает встроенную гравитацию по оси Y и честно притягивает игрока и любые объекты (Rigidbody) строго к центру сферической планеты.
* **Chunk Generation:** Сфера динамически разделяется на чанки. Отрисовываются только те элементы ландшафта, которые находятся близко к камере или игроку, что гарантирует высокий FPS и отличную оптимизацию.
* **Subdivision (1-4):** Возможность гибко настраивать детализацию сетки (Mesh) планеты. От легких астероидов до высокополигональных планет.
* **2-Click Generation (HeightMap & Textures):** Инструмент автоматически считывает черно-белую карту высот (Heightmap) из интернета, выдавливает честный 3D-рельеф (горы, кратеры, каньоны) и бесшовно натягивает текстуру материала.
* **In-Editor Terraforming:** Возможность редактировать рельеф планеты вручную прямо в редакторе Unity с помощью удобных кистей.

## 🛠 Установка и использование (How to use)

1. Скачайте этот репозиторий и перенесите файлы в папку `Assets` вашего проекта Unity.
2. Создайте пустой объект на сцене и добавьте на него компонент `PlanetTerrainGenerator`.
3. В инспекторе укажите желаемый радиус, загрузите карту высот (HeightMap) и текстуру планеты.
4. Нажмите кнопку **Generate**.
5. Чтобы объекты притягивались к планете, отключите галочку `Use Gravity` в их `Rigidbody` и добавьте скрипт кастомной физики, указав сгенерированную планету в качестве цели.
